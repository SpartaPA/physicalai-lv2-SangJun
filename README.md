# Lv2 Module 1 — OpenCR·다이나믹셀 통합 4문제

## 환경
- Raspberry Pi 4 Model B / Ubuntu Server 22.04
- OpenCR 1.0
- Dynamixel ID 12 / Protocol 2.0 / 1 Mbps
- USB Serial `/dev/ttyACM0`
- 예제 `opencr_position_p.ino`

## 결과
- 문제 1: 펌웨어 컴파일·업로드 및 P 제어 실행 확인
- 문제 2: target/current/error 및 피드백 경로 분석
- 문제 3: Kp=4와 Kp=2 비교
- 문제 4: ROS2–micro-ROS Agent–OpenCR–Dynamixel 가상 설계
