# Module 3 - ROS 2 Topic Inspection

## Raw Image
Topic: /camera/camera/color/image_raw
Type: sensor_msgs/msg/Image
Publisher: /camera/camera
Subscriber: perception_node, rviz, and others
Status: Image received and displayed in rqt_image_view

## Mask
Topic: /perception/mask
Type: sensor_msgs/msg/Image
Publisher: perception_node
Status: Image received and displayed in rqt_image_view

## Detection Overlay
Topic: /perception/debug_image
Type: sensor_msgs/msg/Image
Publisher: perception_node
Status: Image received and displayed in rqt_image_view

## Detection Coordinates
Topic: /target
Type: geometry_msgs/msg/PointStamped
Publisher: perception_node (2 publisher endpoints observed)
Status: Message received using ros2 topic echo --once

## 측정 기록 간 차이

이 파일의 기존 `/target` 기록은 publisher endpoint 2개를 관측했다고 적고 구독자는 구체적으로 기록하지 않습니다. `live_environment.txt` 스냅샷(2026-10-14 15:39:50 +09:00)에는 publisher endpoint 1개(`/perception_node`)와 subscription count 0이 기록되어 있습니다. 두 자료의 측정 시점이 같은지 확인되지 않아 차이의 원인을 판정하지 않으며 어느 기록이 더 정확한지도 단정하지 않습니다.

두 기록 모두 `/target` 타입을 `geometry_msgs/msg/PointStamped`로 적고 있습니다.
